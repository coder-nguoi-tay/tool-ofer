# Offline HTML simulator

Run `node mock-html-simulator.mjs` from the project root.

The simulator reads every saved HTML snapshot, writes aggregate counts to `log-structure-summary.json`, and writes `offer-log-catalog.json` with every unique offer it can recover, duplicate counts, source snapshot names, and form-based offer captures excluded from the mock. Run `node mock-pages/capture-form-assets.mjs` to refresh the local CSS, image and font cache from the selected saved form. The simulator then builds one `offer-sample.html` with ten sequential pages: the captured Alpha Intent information form first, followed by nine distinct captured answer pages. The selected question pages cover the five answer structures found in the logs. The first page keeps the captured Submit button disabled until its required visible fields and disclaimer are complete; the checkbox is rendered visibly in the offline fixture. Page ten contains every unique actionable or informational offer recovered from the saved HTML. For actionable entries, the simulator selects a captured answer or primary CTA locally and records the source action ID; informational entries have no invented CTA. No captured follow-up page was present for the offers. Form-based offerwall captures are listed in the catalog but excluded so only the information-entry page contains a `<form>`. The selected form's source scripts are removed, assets are served from `assets/`, external navigation is disabled, and form submission is blocked. Each run overwrites `offer-actions.tmp.jsonl` with synthetic action records and audits form blocking and completion, all nine answer pages, the AI disclaimer, every captured offer action, and static informational entries.

`uplevel-zulily-offline.html` is a local copy of the saved Uplevel Rewards page source, with the captured informational sections and original question, loading, and email markup. Its first four funnel states use local screenshots from the captured page; the email state uses the source HTML. Original scripts, trackers, remote URLs, form actions, and hidden campaign values are removed. Run `node --test tests/mock-pages/uplevel-funnel.test.mjs` to exercise the local flow with the production question selector and submit-button finder. Continue records a local test status and sends no data.
